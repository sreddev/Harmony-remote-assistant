The Harmony 600, readable without Logitech

The remote's configuration is backed up over USB and read back locally into its devices, IR codes, button names and activities, with no Logitech software or server involved. Nothing has been written to the remote. This page records how, what came out, and what comes next.

How it was done

In order. Every USB step only read.

  1. Took MyHarmony apartA 2013 browser shell running a Silverlight app from Logitech's servers, which drives the remote through a USB plugin and about 230 protocol templates.
  2. Assessed going offlineFour proposals; the blocker was the server that compiles devices and activities into the remote's configuration file.
  3. Backed up with AfterglowIts libconcord, taken from the checksum-verified Windows release, identified the remote and read /cfg/usercfg. No driver was changed.
  4. Found the formatThe file is the Harmony One's GSPM image with a different base, index and constant; the One's checksum matches exactly.
  5. Taught Afterglow the 600A read-only profile and backend: section mapping, command objects, the 54-key table, the LCD font, page labels and activity names.
  6. Evaluated a builderharmony-explorations builds 600 configurations from a recipe and has run one on a real 600.
  7. Saved and documentedEverything is in local git repositories, with a process document and a format document.

Building configs

harmony-explorations (MIT) builds a whole 600 configuration from a recipe of devices and activities, without any Logitech file, and has written one to a real 600 that ran it. 16 of its 68 requirements for the 600 are proven by tests, among them build, verified write, and backup and restore. Still open: turning an existing configuration into an editable recipe, catalogue search, and a written procedure for writing to a new owner's remote.

To rebuild this remote's setup it needs a catalogue entry per device. The configuration stores no make or model, so those have to come from MyHarmony or from matching the recovered IR codes against the IR archive (276,000 devices, CC0, already downloaded).

Your decisions

Needs approval

Run the builder

Installing harmony-explorations' dependencies runs third-party code, so it needs your permission.

cd harmony-explorations
npx pnpm@11.20.0 install --frozen-lockfile
Needs input

Device models

The make and model of the TV, the AVR and the HiFi, as MyHarmony lists them. Or ask for a search of the IR archive by the recovered codes.

Optional

Contribute to Afterglow

The 600 backend reuses the One's reader, which Afterglow's removability rule forbids. A copy or a shared module would fix it; that choice is the maintainers'.

Nothing will be written to the remote without your explicit approval, and only after a fresh backup.
